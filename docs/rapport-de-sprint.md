# Rapport de sprint (modèle)

Un **rapport d'activité** dit où en est le travail par rapport à ce qui était prévu : ce qui est fait, ce qui reste à faire, l'écart, les obstacles et les décisions attendues. Après chaque revue, le Scrum Master copie le modèle ci-dessous en commentaire de l'issue « Sprint N – suivi » et le complète avec l'équipe. Le même modèle servira à chaque étape de votre projet certifiant.

```markdown
**Rapport du sprint N · (date) · (prénom du Scrum Master)**

- Objectif de sprint : atteint / partiellement atteint / non atteint
- Fait (fusionné, en ligne) : #… US-… (… points) · total : … points
- En cours (non fusionné, retour au backlog) : #… US-… (raison en une phrase)
- Reste à faire : … points dans le Product Backlog (… stories à estimer)
- Écart : … points terminés sur … prévus ; cause principale : …
- Obstacles : … (levé, ou à lever : par qui ?)
- Décision attendue : …

**Réunion avec le Product Owner (revue)**

- Retours classés : anomalie → nouvelle issue · nouvelle demande → nouvelle issue · préférence → notée
- Décisions : …
- Actions (qui, quand) : …
- Questions ouvertes : …
```
